# Praktikum 6 — JavaScript DOM dan Event Handling

## Deskripsi
Proyek ini dibuat untuk memenuhi tugas Praktikum 6 yang membahas penggunaan JavaScript DOM dan Event Handling pada halaman web.

## Teknologi yang Digunakan
- HTML
- 
- CSS
- JavaScript

## Struktur File
- `index.html` — Struktur halaman web.
- `style.css` — Tampilan dan gaya halaman web.
- `script.js` — Logika JavaScript dan interaksi pengguna.
- `README.md` — Dokumentasi proyek.

## Fitur
1. Mengubah konten HTML menggunakan JavaScript DOM.
2. Menampilkan waktu ketika tombol diklik.
3. Mengubah gaya teks menggunakan `classList.toggle()`.
4. Menghitung jumlah karakter yang dimasukkan.
5. Memvalidasi formulir pendaftaran berdasarkan nama, email, dan usia.
6. Menambahkan daftar tugas dan menandai tugas yang selesai.

## Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Pastikan file `index.html`, `style.css`, dan `script.js` berada dalam folder yang sama.
3. Buka file `index.html` melalui browser.
4. Coba setiap tombol dan fitur yang tersedia pada halaman web.

## Tujuan Praktikum
Memahami cara memanipulasi elemen HTML menggunakan DOM, menangani event, mengubah tampilan elemen, membaca input pengguna, serta melakukan validasi formulir menggunakan JavaScript.

## Penutup
Melalui praktikum ini, diharapkan mahasiswa dapat memahami dasar penggunaan JavaScript DOM dan Event Handling untuk membuat halaman web yang interaktif.
